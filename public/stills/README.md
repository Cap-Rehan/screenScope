# Your own stills (not committed)

Drop a frame named `master.jpg` here and the aspect-ratio simulator uses it instead of the NASA photo.
For the crop demo to make sense, the image should be about 1.43:1 (e.g. 2000 × 1400) with something important near the top and bottom edges.

Everything in this folder except this README is gitignored. Film stills are usually copyrighted, so whether you publish a build containing one is your call.
